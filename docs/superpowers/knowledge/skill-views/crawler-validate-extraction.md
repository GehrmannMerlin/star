# crawler-validate-extraction 知识视图

> 本视图是 `crawler-validate-extraction` Skill 的独立知识视图，只保留与"解析与数据质量诊断、修复顾问"职责相关的知识。来源身份、版本与许可证事实由共享证据层统一维护，本视图通过稳定证据卡 ID 引用，不复制原始来源元数据。

## 定位、触发与排除项

- **定位**：面向 Agent 的解析与数据质量诊断、修复顾问；依托固定版本资料帮助 Agent 检查项目的 HTML、DOM、JSON、结构化数据、文本编码、Selector、字段映射和数据校验逻辑，发现字段缺失、错位、过期、冲突、乱码以及"程序成功但数据错误"等问题。
- **不是**：项目中的生产解析器；不承担项目的生产解析功能；不是修复器、规划器、记忆服务、RAG、索引服务、上下文框架或运行组件。
- **触发**：用户要求检查解析与数据质量相关设计或故障；已确认问题涉及字段缺失、错位、过期、冲突、乱码或"程序成功但数据错误"。
- **排除**：不负责联网抓取或浏览器渲染（分别交给对应领域 Skill）；具体 TypeScript/Crawlee 等框架 API/版本问题交给重点技术栈 Skill；证据存储完整性交给 `crawler-manage-evidence-storage`；不绕过登录/验证码/访问控制/WAF；不把外部条件或未知项伪装成已修复；不用默认值或猜测掩盖缺失与冲突；不生成 `writing-plans`。

## 最低证据输入

- 项目上下文（处理 Stellaris 问题时为 `stellaris-crawler-context` 项目上下文包路径）。
- 解析代码、配置、依赖版本、原始页面证据、抽取结果、金标预期、复现证据。
- 固定版本资料（批次 3：jsoup、mozilla/readability、whatwg/url）。

## 知识主题与证据卡映射

### HTML/DOM 解析

- 判断 HTML 解析、DOM 节点模型、正文提取是否符合固定版本行为；解析容错差异、正文含噪声/截断是常见问题。
- 证据卡：[[VE-HTML-001]]（HTML 解析行为）、[[VE-HTML-002]]（DOM 节点模型）、[[VE-HTML-003]]（正文提取算法）。
- 依据固定版本：jsoup `org/jsoup/parser`、`org/jsoup/nodes`；readability `Readability.js`、`JSDOMParser.js`。

### JSON/结构化数据

- 判断 JSON/结构化数据解析、URL 引用处理、字段映射是否符合固定版本行为；JSON-LD 字段缺失/错位是常见问题。
- 证据卡：[[VE-JSON-001]]（JSON/结构化数据解析）、[[VE-JSON-002]]（结构化数据引用处理）、[[VE-JSON-003]]（数据字段映射）。
- 依据固定版本：readability `Readability.js`（`JSON.parse`、`_getArticleMetadata`）；whatwg/url `url.bs`。

### 文本编码

- 判断字符集检测/编码转换、百分号编码是否符合固定版本行为；乱码/编码声明错误是常见问题。
- 证据卡：[[VE-ENC-001]]（字符集检测与处理）、[[VE-ENC-002]]（百分号编码）。
- 依据固定版本：jsoup `helper/DataUtil.java`；whatwg/url `url.bs`。

### Selector/字段映射

- 判断 CSS 选择器、字段提取、内容评分是否符合固定版本行为；选择器未命中/误选、字段错位是常见问题。
- 证据卡：[[VE-SEL-001]]（CSS 选择器语义）、[[VE-SEL-002]]（字段提取与元数据）、[[VE-SEL-003]]（内容评分）。
- 依据固定版本：jsoup `org/jsoup/select/Evaluator.java`、`Collector.java`；readability `Readability.js`。

### 数据校验/数据质量

- 判断内容安全清洗、内容质量判定是否符合固定版本行为；清洗丢失合法内容、可读性误判是常见问题。
- 证据卡：[[VE-VAL-001]]（内容安全清洗）、[[VE-VAL-002]]（内容质量判定）。
- 依据固定版本：jsoup `org/jsoup/safety`；readability `Readability-readerable.js`。

## 隐蔽数据错误重点

- 特别识别"程序成功但数据错误"的隐蔽问题：程序不报错但字段缺失、错位、乱码、过期、冲突。
- 检测方法：结合金标预期比对抽取结果，使用已保存证据执行小规模离线回放。
- 禁止用默认值或猜测掩盖字段缺失与冲突；必须暴露真实数据问题。

## 版本化判断规则

- 每条判断依据必须追溯到固定版本资料（ref＋Commit）、证据卡、上下文包条目或决策日志节号；只给仓库首页或没有版本的引用不满足要求。
- 明确区分事实、证据、综合推断与未知项；综合推断必须显式标记"推断"，不得伪装成资料中的确定结论。
- 不得因新技术更新默认要求升级；是否升级以证据和项目约束为准。
- 不同版本行为分别保存，禁止把新版本结论回填到旧版本卡片。

## 常见故障模式

| 故障模式 | 证据卡 | 典型根因方向 |
|---|---|---|
| DOM 解析结果与预期不符 | [[VE-HTML-001]] | 解析容错差异、ParseSettings 配置 |
| 节点缺失/错位 | [[VE-HTML-002]] | DOM 遍历错误、选择器未命中 |
| 正文含噪声/截断 | [[VE-HTML-003]]、[[VE-SEL-003]] | 正文提取评分偏差、页面结构变化 |
| JSON-LD 字段缺失/错位 | [[VE-JSON-001]]、[[VE-JSON-003]] | 结构化数据解析、字段映射错误 |
| URL 引用断裂/重复 | [[VE-JSON-002]] | URL 规范化错误 |
| 乱码/编码声明错误 | [[VE-ENC-001]] | 字符集检测失败、编码转换错误 |
| URL 编码异常 | [[VE-ENC-002]] | 百分号编码错误 |
| 选择器未命中/误选 | [[VE-SEL-001]] | 选择器错误、页面结构变化（页面行为变化分类） |
| 字段错位/缺失 | [[VE-SEL-002]]、[[VE-JSON-003]] | 字段映射错误、元数据缺失 |
| 清洗丢失合法内容/含噪声 | [[VE-VAL-001]] | 白名单规则错误 |
| 可读性误判 | [[VE-VAL-002]] | minScore/minContentLength 阈值、页面结构变化 |
| 站点拒绝/访问限制/结构特殊 | [[VE-HTML-003]] | 外部条件，只能合规降级/等待/终止 |

## 证据不足与冲突处理

- 证据不足时不得把结论判定为确定根因；保持候选假设并标记未知项，只提出最小补充取证或离线回放。
- 现场证据、项目上下文、已批准要求冲突时并列报告，不静默覆盖任一来源。
- 未解决的声明标记为不确定（非确定性），不得伪装成确定结论。
- 固定版本证据卡与既有诊断记录不得被静默改写；更新只通过新增修订进行。
- 外部条件（站点拒绝/访问限制/结构特殊）只能给合规降级/等待/终止结论，不得伪装成已修复。
- 隐蔽数据错误必须暴露，不得用默认值或猜测掩盖。

## 输出与交接

- 输出可追溯诊断记录：问题证据、分类（代码缺陷/配置错误/版本兼容/页面行为变化/外部条件/未知项，含置信度）、根因或待验证假设、影响范围、修复方向、回归样例。
- 根因和方向获批后，交接给 `crawler-writing-plans-bridge` 作为规划输入；用户未批准前不交接。
- 交接遵守主决策日志 §33-36：可落盘结构化记录＋简短摘要；双层存储；敏感信息落盘前脱敏。
- 处理 Stellaris 问题时，先读取 `stellaris-crawler-context` 项目上下文包路径。

## 排除项与禁止

- 不承担项目的生产解析器功能。
- 不负责联网抓取或浏览器渲染。
- 不绕过登录、验证码、访问控制或 WAF。
- 不把外部条件或未知项伪装成已修复。
- 不使用默认值或猜测掩盖字段缺失与冲突。
- 不修改爬虫代码、`manifest.md`、第三方仓库；不初始化 Git。
- 不把密钥、Cookie、认证请求头写入诊断记录。
