# crawler-automate-browsers 知识视图

> 本视图是 `crawler-automate-browsers` Skill 的独立知识视图，只保留与"跨框架浏览器自动化诊断、修复顾问"职责相关的知识。来源身份、版本与许可证事实由共享证据层统一维护，本视图通过稳定证据卡 ID 引用，不复制原始来源元数据。

## 定位、触发与排除项

- **定位**：面向 Agent 的跨框架浏览器自动化诊断、修复顾问；依托固定版本资料帮助 Agent 检查项目的浏览器升级条件、动态渲染、等待条件、上下文隔离、资源拦截、公开网络请求观察与 CPU/内存/页面生命周期。
- **不是**：项目中的生产浏览器 Worker；不承担项目的生产页面抓取和渲染；不是修复器、规划器、记忆服务、RAG、索引服务、上下文框架或运行组件。
- **触发**：用户要求检查浏览器自动化相关设计或故障；已确认问题涉及浏览器升级条件、动态渲染、等待条件、上下文隔离、资源拦截、公开网络请求观察或 CPU/内存/页面生命周期。
- **排除**：Playwright 具体 API/配置/版本问题交给 `crawler-use-playwright`；业务字段正确性交给 `crawler-validate-extraction`；不默认固定长等待或把 `networkidle` 当通用完成条件；不绕过登录/验证码/访问控制/WAF；不把外部限制或未知项伪装成已修复；不生成 `writing-plans`。

## 最低证据输入

- 项目上下文（处理 Stellaris 问题时为 `stellaris-crawler-context` 项目上下文包路径）。
- 浏览器代码、配置、依赖版本、日志、Trace、DOM、截图、网络记录、复现证据。
- 固定版本资料（批次 3：w3c/webdriver 规范 `index.html`；Playwright 细节留给第五批 Skill 16）。

## 知识主题与证据卡映射

### 会话与上下文隔离

- 判断会话创建/能力协商、上下文切换、全局状态是否符合 WebDriver 规范；会话状态泄漏、上下文错乱是常见问题。
- 证据卡：[[AB-SESS-001]]（会话与能力协商）、[[AB-SESS-002]]（上下文与窗口管理）、[[AB-SESS-003]]（全局状态与隐私边界）。
- 依据固定版本：w3c/webdriver `index.html` 的 Capabilities、Sessions、Contexts、Global State、Privacy、Security 章节。

### 等待条件与导航

- 判断等待条件、导航与文档就绪、脚本执行是否符合规范；固定长等待不足/超时、`networkidle` 过度通用化是常见问题。
- 证据卡：[[AB-WAIT-001]]（超时类型与语义）、[[AB-WAIT-002]]（导航与文档就绪）、[[AB-WAIT-003]]（脚本执行）。
- 依据固定版本：w3c/webdriver `index.html` 的 Timeouts、Navigation、Document、Executing Script 章节。

### 元素与交互

- 判断元素检索、可交互性、动作输入是否符合规范；选择器失效、元素不可交互、动作无效是常见问题。
- 证据卡：[[AB-ELEM-001]]（元素检索）、[[AB-ELEM-002]]（可交互性与元素状态）、[[AB-ELEM-003]]（动作与输入）。
- 依据固定版本：w3c/webdriver `index.html` 的 Elements、Interactability、Retrieval、State、Interaction、Actions 章节。

### 资源拦截与网络观察

- 判断代理配置、公开网络请求观察是否符合规范；代理未生效、请求观察误用是常见问题。
- 证据卡：[[AB-NET-001]]（代理能力）、[[AB-NET-002]]（公开网络请求观察）。
- 依据固定版本：w3c/webdriver `index.html` 的 Capabilities、Proxy 章节。

### 生命周期与资源

- 判断页面生命周期与资源观察是否符合规范；上下文泄漏、CPU/内存持续增长是常见问题。
- 证据卡：[[AB-LIFE-001]]（屏幕捕获与打印）、[[AB-LIFE-002]]（页面生命周期与资源观察）。
- 依据固定版本：w3c/webdriver `index.html` 的 Screen capture、Print、Sessions、Contexts 章节。

## 版本化判断规则

- 每条判断依据必须追溯到固定版本资料（ref＋Commit）、证据卡、上下文包条目或决策日志节号；只给仓库首页或没有版本的引用不满足要求。
- 明确区分事实、证据、综合推断与未知项；综合推断必须显式标记"推断"，不得伪装成资料中的确定结论。
- 不得因新技术更新默认要求升级；是否升级以证据和项目约束为准。
- 不得默认使用固定长等待或把 `networkidle` 当作通用完成条件；等待应针对动态内容使用条件等待。
- 不同版本行为分别保存，禁止把新版本结论回填到旧版本卡片。

## 常见故障模式

| 故障模式 | 证据卡 | 典型根因方向 |
|---|---|---|
| 会话创建失败/能力协商不匹配 | [[AB-SESS-001]] | Capabilities 配置、会话生命周期 |
| 窗口/上下文错乱 | [[AB-SESS-002]] | 句柄管理、上下文切换错误 |
| 固定长等待不足/超时 | [[AB-WAIT-001]]、[[AB-WAIT-002]] | 未用条件等待、page load timeout、动态内容未就绪 |
| `networkidle` 被通用化 | [[AB-WAIT-002]] | 把非规范完成条件当通用 |
| 脚本执行超时 | [[AB-WAIT-003]] | script timeout、异步脚本等待错误 |
| 元素找不到/选择器失效 | [[AB-ELEM-001]] | 页面结构变化（页面行为变化分类）、隐式等待未生效 |
| 元素不可交互 | [[AB-ELEM-002]] | 可见性/遮挡、状态判断错误 |
| 动作无效 | [[AB-ELEM-003]] | 输入源/时序错误 |
| 代理未生效 | [[AB-NET-001]] | 代理能力配置、noProxy |
| 动态资源加载观察错误 | [[AB-NET-002]] | 请求时序、拦截配置 |
| 上下文泄漏/资源持续增长 | [[AB-LIFE-002]] | 会话/上下文未关闭 |
| 站点验证码/访问控制/WAF/指纹 | [[AB-SESS-003]]、[[AB-NET-002]] | 外部限制，只能合规降级/等待/终止 |

## 证据不足与冲突处理

- 证据不足时不得把结论判定为确定根因；保持候选假设并标记未知项，只提出最小补充取证或受控浏览器复现。
- 现场证据、项目上下文、已批准要求冲突时并列报告，不静默覆盖任一来源。
- 未解决的声明标记为不确定（非确定性），不得伪装成确定结论。
- 固定版本证据卡与既有诊断记录不得被静默改写；更新只通过新增修订进行。
- 外部限制（验证码/访问控制/WAF/指纹检测）只能给合规降级/等待/终止结论，不得伪装成已修复。

## 输出与交接

- 输出可追溯诊断记录：问题证据、分类（代码缺陷/配置错误/版本兼容/页面行为变化/外部限制/未知项，含置信度）、根因或待验证假设、影响范围、修复方向、浏览器层测试建议。
- 根因和方向获批后，交接给 `crawler-writing-plans-bridge` 作为规划输入；用户未批准前不交接。
- 交接遵守主决策日志 §33-36：可落盘结构化记录＋简短摘要；双层存储；敏感信息（含截图内容）落盘前脱敏。
- 处理 Stellaris 问题时，先读取 `stellaris-crawler-context` 项目上下文包路径。

## 排除项与禁止

- 不承担项目的生产页面抓取和渲染。
- 不默认使用固定长等待或把 `networkidle` 当作通用完成条件。
- 不绕过登录、验证码、访问控制或 WAF。
- 不执行过度浏览器复现或无效轰击；诊断复现限小规模、隔离、合规。
- 不修改爬虫代码、`manifest.md`、第三方仓库；不初始化 Git。
- 不把密钥、Cookie、认证请求头写入诊断记录。
