## 四、后续开发协议

1. **每次只推进一个模块**：当前模块计划通过用户审阅前，不开始下一个。
2. **必走流程**：brainstorming → 设计规格 → 实施计划 → 用户批准 → 内联实施（先失败测试）→ 全量回归全绿 → 更新进度总账。
3. **决议记录**：新用户决议追加开发期决策日志（连续 R-xx）；不覆盖历史决议。
4. **真实网络边界**：Canary/真实抓取逐项授权；Git 初始化/常驻服务不自动执行。
5. **权威分层**：最新用户决议 > 开发期决策日志 > 已批准设计 > 历史设计。
6. **发现冲突**：列出事实/冲突条款/影响/可选处理/推荐，等待用户决议，不自选边。
